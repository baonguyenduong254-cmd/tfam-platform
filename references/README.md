# Thư viện tham khảo cho AI

Đây là danh mục có chọn lọc, không phải kho để chép tất cả repo vào và không phải dữ liệu huấn luyện model.

Mỗi reference cần: URL upstream, mục đích với TFAM, trạng thái review, exact commit/tag khi dùng, license, file hoặc kỹ thuật áp dụng và lý do chọn.
Danh mục ban đầu chỉ là ứng viên; chưa cài thêm package và chưa đưa code ngoài vào TFAM.

## Cách dùng
1. Bắt đầu từ một vấn đề cụ thể, như carousel banner trên mobile.
2. Đọc docs chính thức và các file liên quan; không nạp toàn bộ repo một cách máy móc.
3. Kiểm tra tương thích với stack TFAM sau khi source v209 đã nhập.
4. Ghi exact revision, kiểm tra license và giữ attribution khi áp dụng.
5. Dùng dependency hiện có nếu phù hợp. Không chạy install script chỉ vì upstream yêu cầu trong README.
6. Đo kết quả với tiêu chí của issue, không dùng độ đẹp của demo thay cho hiệu năng và tính đúng.
