# TFAM media production

Read docs/AI-OPERATING-WORKFLOW.md and use the media route. This skill routes work; it does not install or connect an image/video service.

Derive subject, destination, aspect ratio, duration, audio/captions and acceptance criteria from the request and current scene. Preserve approved characters, faction symbols, tone and existing artwork. Resolve routine format choices yourself; ask only for essential missing identity/source material or a materially new cost that needs authorization.

Discover available image/video tools and read the provider's installed skill before calling them. Prefer native image generation for stills; use an available video service for generated footage; use an available narrator/captions/editing workflow for precise speech and composition. Available tool metadata does not prove a signed-in session or entitlement. Never invent a render ID, preview or completed export.

Use existing source images when fidelity matters. Label synthetic media accurately and keep original author assets. Do not clone a real person's voice or likeness without the relevant authorization. Do not copy runtime/provider skills from this host into the repo or place service credentials in Git.

For narrated work, align the script with TFAM canon before synthesis, then preserve wording and voice identity through timing/captions. For generated footage, inspect identity/composition continuity and unwanted text. For coded motion, prefer the existing stack; a separate cloud Remotion project is optional only when suitable and its license/dependencies are verified. Remotion is a reference, not installed infrastructure.

Inspect representative frames and playback: native dimensions, actual duration, audio sync, subtitle readability, safe margins, flicker, unintended logos and loop seams. A prompt saying UHD does not prove native UHD; report measured dimensions. Deliver the requested finished asset or explicitly identify a preview-only result.

For website integration, provide an optimized export, poster and still/reduced-motion fallback; defer noncritical downloads and avoid adding audible autoplay. Keep large bytes in the approved media store and Git metadata/checksums in the asset catalogue. Generation does not authorize replacing production artwork, writing R2 or publishing. Preserve reversible previous asset references; do not delete old objects as part of an ordinary update.
