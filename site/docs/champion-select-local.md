Status: local only, based on published Sites 218 source 34b03cef4b56571bb147df800a32d2038dc439c5. No DB or R2 writes. Existing repository status documents still describe older releases; they are not production provenance.

## Direction contract

Experience: MOBA selection inside the existing TFAM imperial world. Portraits select; a separate action enters the wardrobe. No carousel of competing full-body figures.

First viewport: central contained Uniform artwork, left identity and safe summary, right three documented attributes. Search and court-group portrait grid beneath. Mobile uses a collapsible roster, with identity, art and stats remaining on the stage.

Existing ivory typography, wine surfaces and aged gold remain. Reuse the supplied cutouts, dedicated roster icons and existing observatory scene. No new raster generation. Missing icons retain initials; no full-body thumbnail substitute.

Selection remounts one art plane: 480 ms horizontal/depth arrival, coordinated 400 ms copy. Repeated selection replaces the current sequence. Idle image displacement is 3 px over 12 s. Offscreen/hidden rendering pauses. Reduced motion retains short feedback. Text is outside moving planes.

Backstage keeps selected identity, central art, left vertical skin choices and right stats. The return restores selected identity from session-local storage. The transition currently uses a 480 ms departure and route arrival, not a true shared-element capture across documents.

Finish: usable local preview and browser behavior check, with visual acceptance still belonging to the owner. No production publish in this prototype task.
