# Eight-rank readable exhibition palette

Root cause: legacy background-clip text and transparent webkit-text-fill on tiers 3–7 overrode plain text colour. Reset text fill, clip, gradient and animation for all rank names, artifact names and detail rarity labels. Distinct dark pigments: slate, umber, blue, violet, green, ochre, garnet and plum; separate pale washes preserve rank identity in headers and cards. All 8 inks tested >=4.5:1 on ivory, paper and their matching wash. Palette JSON and contrast regression included.

## Animated spectrum restoration

Restores animated gradient lettering for Quintessential through Unique (ranks 3–7) using exclusively the dark contrast-tested pigments. Rudimentary–Rare retain solid text. Applied to rank headings, exhibit names and detail rarity badges. Reduced-motion preference keeps the gradient static; forced-colour mode uses system text.
